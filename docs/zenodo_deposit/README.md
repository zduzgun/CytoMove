# Cytomove — Validation Data, Figures, and Analysis Artifacts

This package contains the supporting validation artifacts for the Cytomove preprint,
*"Cytomove: a browser-local and reviewable workflow for scratch wound healing assay quantification"*
(Zekeriya Düzgün, Giresun University; ORCID 0000-0001-6420-6292).

It is the frozen numerical source of truth and the figure set behind the reported
Cytomove-versus-WHST comparison, deposited so the results can be inspected and reproduced.

## Contents

| File / folder | Description |
| --- | --- |
| `validation_master.xlsx` | Paired WHST and Cytomove per-frame measurements (area, width), dataset-level diagnostics (MAPE, median, max, mean signed error, Pearson r), discrepancy-resolution table, and manuscript notes. Sheets: `summary`, `paired_measurements`, `worst_rows`, `discrepancy_resolution`, `manuscript_notes`. |
| `selected_input_manifest.csv` | Per-frame provenance table for the 31 validation measurements, including dataset, frame index, time label, analysis input filename, source dataset/origin, original source identifier, redistribution status, license/rights note, and derived-output location. |
| `input_images/author_phone/` | The 9 author-acquired smartphone-through-eyepiece raw JPG images used for the `cell_phone_HK`, `cell_phone_M8F`, and `cell_phone_MK` validation sets. These images are included because they were acquired by the author. |
| `derived_outputs/` | Frozen Cytomove group-metric exports and WHST result workbooks used to build the paired validation summary. These are included as intermediate evidence between the input-image manifest and `validation_master.xlsx`. |
| `deposit_file_manifest.csv` | File-level manifest for this deposit, including relative path, file size, and SHA-256 checksum. |
| `figures/` | Manuscript Figures 1–5 and Supplementary Figures S1–S2 in PDF and SVG vector formats. |
| `Cytomove_manuscript_submission.pdf` | The corresponding preprint manuscript. |
| `.zenodo.json` | Zenodo deposit metadata (title, creator, license, keywords, related identifiers). |

## Datasets and provenance

The five validation image sets comprise 31 paired measurements:

- `csma_sample_11` (n = 11) — clean comparator time course.
- `whad_mcf7_11` (n = 11) — phase-contrast MCF-7 time course.
- `cell_phone_HK`, `cell_phone_M8F`, `cell_phone_MK` (n = 3 each) — smartphone-through-eyepiece brightfield stress sets.

Image provenance:

- **WHAD-MCF7** source images were derived from the WHAD/CAMAD dataset — Iheme et al., 2024, Zenodo, CC BY 4.0, [doi:10.5281/zenodo.12806149](https://doi.org/10.5281/zenodo.12806149).
- **CSMA** sample images and output context were derived from the public [CSMA WoundHealing repository](https://github.com/AminaSagymbayeva/CSMA_WoundHealing) and the associated publication — Pham et al., 2025, *IEEE Access*, [doi:10.1109/ACCESS.2025.3561607](https://doi.org/10.1109/ACCESS.2025.3561607).
- **Smartphone-through-eyepiece** images were acquired by the author.

All Cytomove overlays, paired measurements, and figures were generated by the author.
**Raw third-party WHAD/CAMAD and CSMA image archives are not redistributed here**; obtain them
from their original sources under their own licenses. The exact selected third-party frame
identifiers are provided in `selected_input_manifest.csv`. The author-acquired phone images
used in the validation are included in `input_images/author_phone/`.
