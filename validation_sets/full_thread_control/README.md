# Cytomove HUVEC Control vs FDI validation set

This folder contains the bundled Cytomove 1.0 tutorial and validation image set.

- Cell model: HUVEC wound healing scratch assay
- Conditions: Control and FDI
- Replicates: 3 control groups and 3 FDI groups
- Time points: 0h, 24h, and 48h for each group
- Total images: 18 JPG files

The images are provided by the Cytomove author for Cytomove tutorial, validation, review, and demonstration workflows. They are intended to let users reproduce the guided in-app workflow from Image QC through Analysis, Publication Figure Builder, and export.

Recommended citation in tutorials or derived examples: "Cytomove bundled HUVEC Control vs FDI validation set."
