Cytomove User Guide.

This guide explains the practical Cytomove 1.0 workflow for wound healing scratch assay analysis: loading local images, reviewing Image QC, tuning analysis parameters, making manual corrections, building figures, and exporting publication-ready results.

Best starting point

Use this page when you want button-level guidance. Use the shorter scratch assay guide for the scientific overview.

Open Web App

Quick start

  1. Open the Cytomove web app or desktop app.
  2. Use Open images or drag-and-drop to load a time-series group.
  3. Name the group clearly, for example HUVEC control r1 or FDI r2.
  4. Review the first image in Image QC, then crop and orient the image series.
  5. Continue to Analysis, apply settings, and inspect the calculated contour overlay.
  6. Open Publication Figure Builder to create a single-group figure, Control vs Treatment figure, or multi-treatment figure.
  7. Export the figure and supporting files when the preview reflects the reviewed analysis.

Cytomove is intentionally reviewable. If the preview looks wrong, return to Image QC or Analysis before exporting. A clean export should be the result of a visible review path, not a hidden automatic measurement.

Image QC

Image QC is the first checkpoint. It prevents avoidable measurement errors before segmentation starts. Use it to create a group, review every time point, crop the field of view, correct scratch orientation, fine-rotate tilted images, and exclude images that should not contribute to the group analysis.

Loading a group

When several images are selected together, Cytomove asks for a group name before creating the reviewable image group. Keep the group name meaningful because it will later appear in replicate lists, Builder controls, and exported files.

Crop and orientation

Use Adjust crop to reveal the crop rectangle, drag the rectangle or its handles until the wound field is centered, then use Save crop. If later images share the same field of view, the saved crop can be carried forward so the series stays consistent.

The scratch orientation should describe the wound geometry, not the camera frame. Vertical scratch is the usual left-to-right wound gap. If the wound gap is top-to-bottom, use horizontal scratch and rotate if needed before analysis.

Analysis parameters

The Analysis step converts the reviewed image into a wound mask and contour. Start with the preset that best matches the microscopy mode, usually brightfield normal cells for typical scratch assay images. Then click Apply and inspect the contour lines.

Threshold and variance radius

Threshold controls the separation between wound and cell-covered regions. Variance radius changes how local texture is interpreted. Moving the radius can improve brightfield images where cell texture, illumination, or microscope field artifacts confuse a simple intensity threshold.

Islands and small regions

The island handling controls decide how tiny internal components are treated. Use trace or ignore tiny islands when speckles or debris are being counted as biologically meaningful wound fragments. After each change, click Apply again and compare the contour overlay.

Apply to group

Use Apply to group only when the current analysis settings are appropriate for the full image series. This keeps replicate analysis faster while still leaving a visible result for review.

Manual correction

Manual correction is for local segmentation problems that remain after the main settings are tuned. It is useful for a missed wound pocket, a false-positive debris region, or a small artifact that should not drive the biological result.

  • Fill area: add a missed wound region when the automatic mask is too conservative.
  • Erase area: remove a false-positive wound region when debris or texture was misclassified.
  • Undo: step back from the most recent correction if the edit was too broad.
  • Reset correction: return to the uncorrected analysis result and start the correction again.

Manual correction should be documented by the exported overlay. Do not use it to force a preferred result; use it to fix a visible local mask error.

Publication Figure Builder

Publication Figure Builder assembles reviewed image groups and analysis results into a figure layout. It is designed for the last review step before export, where the user checks representative images, calculated contour overlays, summary charts, labels, and typography.

Single group

When only one image group exists, Cytomove creates a single-group figure. This avoids a fake Control or Treatment comparison and is useful for method checks, pilot experiments, and one-condition examples.

Control vs Treatment

With two groups, choose the control representative group, the treatment representative group, and the replicate groups that belong to each condition. The Control vs Treatment layout summarizes representative contours, wound closure, and normalized area.

Multi-treatment

For FDI, drug B, drug C, dose groups, or any condition beyond the first treatment, use the multi-treatment template and add extra treatment groups. Each added treatment has its own representative group and replicate selection.

Panel layout and typography

Builder panels can be adjusted so the figure better fits publication space. Use the title fields, font family, title size, weight, labels, and snap-to-grid panel dragging to refine the layout while keeping the scientific content intact.

Analyze missing groups

If a selected group does not yet have stored contours, the Builder shows Analyze missing groups. Click it to complete the missing group analysis before exporting the figure. This keeps Builder previews tied to the current Image QC crop and analysis settings.

Export package

Cytomove exports both compact publication figures and supporting files for independent review. The Builder export can include 600 DPI PNG output, TIFF output when supported, CSV data, chart assets, and a ZIP package for manuscript preparation.

For manual figure assembly, the export package can also include full-size original images and full-size contour-overlay images. The full-size contour-overlay files are useful when a journal, collaborator, or reviewer wants to inspect segmentation on the original-resolution field rather than the Builder preview.

  • CSV metrics: wound area, closure, width, and supporting values.
  • Figure images: publication-style figure previews and 600 DPI outputs.
  • TIFF: high-resolution figure export where browser support allows it.
  • Builder ZIP: combined figure, data, and full-size contour-overlay assets.

Troubleshooting

No images appear after loading

Try a fresh browser tab, then reload the page. If the app was recently updated, a stale browser cache may keep an older script active. The local development server disables stale caching, but public browsers can still hold old files.

The contour does not match the wound

Return to Analysis, adjust the preset, threshold, variance radius, and island handling, then click Apply again. Use Manual correction only after the global settings are close.

The Builder preview says groups need analysis

Use Analyze missing groups. This usually means the group was selected in the Builder before stored contour results existed for all selected images.

Export is disabled

Sign in when full export access is required, verify that selected groups have analysis results, and confirm the Builder preview is available before exporting.
